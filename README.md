# StudySense — Exam Score Predictor 📚

A **Machine Learning regressor** that predicts a student's final exam score from their study habits — hours studied, sleep, attendance, previous score, and extracurricular time — and shows *which habits actually drive the prediction*.

Built as the **Masterclass 1 IBM Bob Project** for the *IBM SkillsBuild – AICTE – BharatCares (CSRBOX) Machine Learning & Applied AI Internship Program 2026*.

## 🚀 How to Run

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. (Optional) regenerate the dataset
python generate_data.py

# 3. Train the model (prints MAE / RMSE / R2 and feature importances)
python train_model.py

# 4. Run the sanity tests
python test_model.py

# 5. Generate the feature-importance chart
python charts.py

# 6a. Run the built-in demo (3 student profiles analyzed)
python app.py

# 6b. Predict your own score
python app.py --hours 6 --sleep 7 --attendance 85 --prev 72 --activities 2
```

## 🧠 How It Works

1. **StandardScaler** — puts every habit on the same scale so no feature dominates unfairly.
2. **Random Forest Regressor** — 200 decision trees that each learn patterns like *"more study hours → higher score"*; their averaged prediction is far more robust than a single tree.
3. **Feature importances** — the model explains itself: it reports how much each habit contributes to the prediction.
4. **Pipeline + joblib + metrics.json** — scaler and forest travel together as one saved object, with the model's typical error stored alongside so every prediction can show its own margin.
